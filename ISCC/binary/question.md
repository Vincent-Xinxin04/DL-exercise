# 二进制漏洞检测竞赛任务说明
## 任务说明
本赛题需要参赛队伍根据给出的训练数据（由真实程序编译得到的二进制可执行文件），分析二进制中的指令序列、控制流结构、函数调用关系、内存操作行为等低层特征，训练模型完成以下两个任务：

**漏洞检测任务（Task 1）**：判别给定二进制文件是否存在漏洞（共2类）：
- `{0：无漏洞文件}`
- `{1：存在漏洞文件}`

**漏洞分类任务（Task 2）**：对于检测为存在漏洞的二进制文件，进一步判别其所属的漏洞类型（基于CWE标准的多分类任务，共86类），例如：
- CWE-121（栈缓冲区溢出）
- CWE-190（整数溢出）
- CWE-416（释放后使用）

## 数据说明
1. 该数据集由真实C/C++程序编译生成的二进制文件构成，每个样本为一个独立的可执行文件。
2. 参赛者需要从二进制中提取特征（如反汇编指令、控制流图、函数调用图等）进行建模。
3. 训练数据集含**39380个**二进制文件及对应标签。
4. 测试数据集含有**30974个**二进制文件。

## 数据字段说明
1. **[训练集]** 包含二进制文件及对应标签信息：`train.csv`
2. **[测试集]** 包含二进制文件编号信息：`test_A.csv`、`test_B.csv`

## 提交要求
提交csv文件，使用**UTF-8**编码格式，文件需包含表头，共三列：`binary_id`、`label`、`cwe_id`。

### 提交文件格式示例
| binary_id   | label | cwe_id  |
| ----------- | ----- | ------- |
| BIN_0000001 | 1     | CWE-078 |
| BIN_0000002 | 1     | CWE-190 |
| BIN_0000003 | 0     |         |
| BIN_0000004 | 0     |         |
| ...         | ...   | ...     |

## 评分标准
竞赛的评估指标为**宏平均F1值**，计算公式如下：
$$F1_{\text{macro}} = 2 \cdot \frac{\text{precision} \cdot \text{recall}}{\text{precision} + \text{recall}}$$

### 宏平均F1值
$$
\text{Macro average } F1 = \frac{1}{K} \sum_{k=1}^{K} F1\ \text{for class } k
$$


# 项目目录结构与文件说明
## 1. 源码文件夹
存放所有模型相关代码（含数据集、数据增强代码等），**必须包含 `train` 和 `test` 代码文件**：
- `train`：用于**训练并保存模型**
- `test`：用于**加载模型并生成预测结果文件**（输出最终结果文件）

## 2. 模型文件夹
存放训练好的模型文件，需与数据安全赛系统提交的最终结果文件一一对应，支持结果复现。

## 3. 提交结果文件夹
存放数据安全赛系统上提交的**最终结果文件**。

## 4. docker容器文件夹
存放可运行模型代码的 Docker 镜像，用于统一、复现模型运行环境。

## 5. requirements.txt 文件
记录模型运行所需的全部环境依赖包。

## 6. README.md 文件
补充说明模型配置、运行方式，确保阅读者可完整复现模型；若使用数据增强方法，需在此详细说明。
